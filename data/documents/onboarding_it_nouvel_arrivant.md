# Onboarding IT — Guide du nouvel arrivant — NovaTech Solutions

**Référence** : GUIDE-IT-001
**Version** : 2.0
**Dernière mise à jour** : 05 janvier 2026
**Propriétaire** : Support IT / RH
**Public concerné** : Nouveaux employés

## 1. Objectif

Ce guide accompagne votre prise en main des outils informatiques de NovaTech Solutions durant votre première semaine.

## 2. Avant votre arrivée

Le Support IT prépare automatiquement, 3 jours avant votre date de début :
- Un compte réseau (identifiant au format `prenom.nom`, envoyé à votre futur manager).
- Une boîte e-mail professionnelle.
- Un poste de travail configuré (portable ou fixe selon votre poste).

## 3. Votre premier jour — checklist

1. Récupérez votre poste de travail auprès du Support IT (bureau 1er étage, ou envoi en cas de télétravail).
2. Connectez-vous avec l'identifiant temporaire fourni ; vous devrez le changer immédiatement (voir la [Politique de gestion des mots de passe](gestion_mots_de_passe.md) pour les règles à respecter).
3. Configurez l'authentification à deux facteurs via l'application **NovaAuth** — obligatoire avant tout accès aux outils internes.
4. Installez votre messagerie professionnelle (préconfigurée sur le poste fourni, aucune action nécessaire si vous utilisez le matériel de l'entreprise).
5. Complétez le module e-learning "Sécurité de l'information" (30 minutes, obligatoire dans les 5 premiers jours).
6. Lisez la [Politique de sécurité IT](politique_securite_it.md) — sa lecture est tracée et obligatoire.

## 4. Outils fournis par défaut

| Outil | Usage |
|---|---|
| Messagerie NovaMail | E-mails professionnels |
| NovaConnect | VPN pour le télétravail |
| NovaAuth | Authentification à deux facteurs |
| Portail RH interne | Congés, notes de frais, annuaire |
| Portail Support IT | Tickets, demandes de matériel |

Des accès supplémentaires (outils métier spécifiques) sont demandés par votre manager via le portail Support IT.

## 5. Questions fréquentes

**Je n'ai pas reçu mes identifiants le jour J**
Contactez votre manager, qui peut faire une demande urgente auprès du Support IT (poste 2200).

**Puis-je utiliser mon ordinateur personnel ?**
Non, sauf dérogation explicite validée par la DSI. Le matériel professionnel est fourni pour garantir un niveau de sécurité homogène (voir la [Politique de sécurité IT](politique_securite_it.md)).

**Que faire si mon poste ne s'allume pas / est défectueux ?**
Ouvrez un ticket "Matériel — urgent" sur le portail Support IT ; un remplacement est fourni sous 24h ouvrées.
